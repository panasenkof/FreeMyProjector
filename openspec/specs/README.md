# Подтверждённые спецификации (текущее поведение)

Сюда попадают только требования **реально реализованных и подтверждённых** функций FreeMyProjector.

Наследованные возможности Free My TV не считаются протестированными на Xiaomi. Пока здесь нет `<capability>/spec.md`: сначала выполняем диагностику, тесты и приёмку первого change.

Работа над будущими функциями ведётся в [../changes](../changes). Порядок переноса описан в [../../docs/SDD_GUIDE.md](../../docs/SDD_GUIDE.md).
