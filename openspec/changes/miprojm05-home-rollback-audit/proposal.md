# Proposal — P-04: безопасный HOME и штатные оптические функции Xiaomi MiProjM05

## Зачем
24.10.2026 пользователь выполнил P-01 через настоящий ADB. Подтверждены `MiProjM05`, `eva`, Android `9` / SDK `28`, прошивка `PQ3B.190705.003.4185`, текущий HOME `com.google.android.tvlauncher/.MainActivity`. Serial/IP не храним в Git.

Исходный `HomeMode.applyFree` одновременно выполняет `cmd package set-home-activity`, `settings put secure screensaver_components` и `pm disable-user --user 0` для пакетов в `targets`. Нельзя считать это безопасным для Xiaomi: может пропасть фокус, трапеция, управление пультом или штатные настройки. `restoreHome` содержит Google TV fallback и `cmd role`, который нельзя считать подтверждённым откатом для Android 9.

## Границы текущего change
- Зафиксировать **реальный**, а не воображаемый HOME, модель и прошивку.
- Определить риски в исходном коде, составить проверяемую процедуру **только чтения** для обнаружения OEM-пакетов.
- Подготовить критерии разрешения дальнейшей реализации обратимой замены HOME.
- До согласования и физических проверок оставить `ModeJob.PROJECTOR_HOME_SWITCH_AUDITED = false`; не выполнять смену HOME, отключение пакетов, изменение заставки, установки/запуски/команды мотора.

## Не-цели
- Не модифицировать Xiaomi через ADB, root или перепрошивку.
- Не объявлять найденные по названию пакеты доказанными контроллерами фокуса и трапеции.
- Не тестировать подписанный APK на реальном устройстве (P-05 после разрешения).
- Не вводить автоматическую синхронизацию с upstream и не переносить чужие команды фокусировки.

## Выход из этапа
Список фактически установленных кандидатов, отмеченные пользователем рабочие пункты заводского меню, протокол отката без отключения OEM-пакетов, отдельное согласование испытания с владельцем. До этого проект остаётся fail-closed.
