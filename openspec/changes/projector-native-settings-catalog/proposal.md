# P-06 — единый каталог существующих настроек MiProjM05

## Why

Владелец подтвердил наличие всех исследованных функций проектора, **кроме 3D**. Сейчас пункты в FreeMyProjector фрагментарны. Вместо копирования HAL/калибровки/управления HDMI добавляем пультовую навигацию к заводским экранам.

## Scope

- Сохранить действующие 7 настроек и добавить восьмой пункт «Функции проектора»; не нарушать HOME guard.
- Группы: Оптика и проекция, Изображение, Источники и HDMI, Звук, Подключения, Система, с русскими (и доступными другими языками) подписями.
- Для подтверждённых OEM aliases выполнять runtime preflight exported/enabled/permission+точной прошивки. Для остальных Android Settings — проверить системный обработчик; у незнакомой ОС — fallback.
- Никакого автоматического запуска фокусировки, калибровки, Bluetooth pair, firmware update, HDMI input change, thermal override, выключения/перезагрузки или 3D.
- Документировать различия DEVICE-OWNER / DEVICE-UI / DEVICE-ADB / CODE и матрицу P-06; hardware acceptance только в обычном APK и отдельно от HOME switch.

## Out of scope

Фактическое управление оптическими моторами, чтение текущих параметров из приватных настроек, прошивка, реальный HOME rollback, автоматический watchdog.
