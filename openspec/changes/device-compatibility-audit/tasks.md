# Tasks: device compatibility audit (P-01)

**Статус:** согласованы ручной и read-only Windows способы. Автотесты пройдены на GitHub Actions ([успешный прогон](https://github.com/panasenkof/FreeMyProjector/actions/runs/39604300344)); **получена фотография реального проектора, модель `MiProjM05`, Android 9 и сборка подтверждены. ADB-скрипт на реальном устройстве не запускался**. Справочник: [PLAN.md](../../../PLAN.md).

## 1. Согласование требований

- [x] 1.1 Пользователь выбрал ручную инструкцию **и** необязательный read-only скрипт Windows.
- [x] 1.2 Принято консервативное обезличивание и ручная проверка перед отправкой: в репозиторий не попадают идентификаторы устройства; публикации автоматически нет.
- [x] 1.3 Согласованный scope отражён в proposal/spec/design/tasks; review CI выполнен.

## 2. Реализация после согласования

- [x] 2.1 Добавлена [инструкция Windows/ручной путь](../../../docs/DEVICE_DIAGNOSTICS_WINDOWS.md) с вариантами пунктов меню и ошибками.
- [x] 2.2 Скрипт [tools/read-only-device-info.ps1](../../../tools/read-only-device-info.ps1) реализован с whitelist ADB-команд; ожидает CI.
- [x] 2.3 В коде предусмотрены неизвестные поля, unauthorized/offline, no-ADB, несколько устройств; ожидает CI.
- [x] 2.4 JSON без серийных идентификаторов, локальная запись только с `-OutputPath`, предупреждение о ручной проверке; ожидает CI.

## 3. Проверки и приемка

- [x] 3.1 Пройден Windows PowerShell тест: модель, Android, API, сборка и HOME при имитации ADB.
- [x] 3.2 Пройдены сценарии no-ADB, offline, unauthorized, disconnected, multiple-devices, unsupported и ADB error.
- [x] 3.3 Проверка кода и валидация whitelist фактически вызванных ADB-команд через mock; реальных сетевых обращений скрипт не создаёт.
- [x] 3.4 Указано, что реальных устройств/прошивок пока не проверяли.
- [x] 3.5 По фотографии раздела «Об устройстве» (22.10.2026) подтверждены модель `MiProjM05`, Android `9`, сборка `PQ3B.190705.003.4185`, ядро `4.9.113`; HOME-компонент не показан и остаётся неизвестным.
- [ ] 3.6 Ручная идентификация документирована; перед архивацией зафиксировать оставшиеся ограничения и решить, требуется ли реальный ADB-тест. Не считать mock-тест подтверждением на прошивке Xiaomi.
