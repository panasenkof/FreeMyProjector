# P-06 — штатные функции в настройках FreeMyProjector

**Реальное сообщение владельца, 25.10.2026:** на MiProjM05/eva сборки `.4185` доступны все функции, перечисленные в нашем исследовании, **кроме 3D**. Это свидетельство пользователя о наличии функций, не отдельный скриншот/проверка каждого пункта, не тест запуска из нового APK и не подтверждение точных URL/Activity.

Источники: [матрица](MIPROJM05_STOCK_FEATURE_MATRIX.md), [индекс](MIPROJM05_RESEARCH_INDEX.md), [OEM Activity](MIPROJM05_ACTIVITY_DISCOVERY.md), [пульт](P04H_REMOTE_PAIRING_DISCOVERY.md).

**Правило:** не переписываем оптические/аудио/HDMI/тепловые сервисы, а открываем существующие заводские настройки. Все переходы — только по явному нажатию с пульта, никаких команд изменения состояния при загрузке. **3D исключён из меню.**

## Реализованные маршруты и ограничения

| Пункты | Куда переходим при OK | Что ещё не доказано |
| --- | --- | --- |
| Фокусировка | `ProjectorFactoryScreens.inspect(FOCUS)` → OEM `FocusActivity` | Runtime экспортируемость/запуск на .4185 — не испытаны |
| Коррекция / авто / калибровка | Один заводской экран `KeystoneActivity`, не запуск калибровки | Конкретные вложенные операции выбираются **уже в OEM UI** пользователем |
| Ориентация, режим изображения, яркость камеры, Bluetooth speaker, голос, сон/питание | Основные настройки `com.formovie.gsettings.ui.activity.MainActivity`, с проверкой OEM/system/exported и точного build | Отдельных подтверждённых deep links нет; fallback в общие Settings |
| HDMI и HDMI zoom | `com.droidlogic.tvinput.settings.TvSettingsActivity` с runtime проверкой, иначе общие настройки | Не меняем HDMI input/zoom автоматически |
| Пульт/Bluetooth | Проверенная по каталогу OEM `AddAccessoryActivity` с runtime guard; fallback | Не сбрасывать существующее сопряжение |
| USB, звук, наушники, Wi-Fi, Cast, приложения, язык, спецвозможности, об устройстве | Стандартные `Settings.ACTION_*` Android 9, только когда Activity экспортирована, включена и принадлежит system app | OEM может не поддерживать intent → фирменные/общие настройки. USB Storage **не файловый браузер** |
| Все заводские настройки | `Settings.ACTION_SETTINGS` | Исходный общий доступ сохранён |

Документация платформы: https://developer.android.com/reference/android/provider/Settings . Сам факт создания пункта в APK **не означает**, что его конечный переход уже проверен на живом MiProjM05.

## Системные подсистемы без собственного переключателя

Оставляем оригинальные OEM пакеты и аппаратные службы: автофокус/мотор, датчики/калибровку, HDMI, Wi-Fi 2.4/5, HDR декодирование, Dolby/DTS, Bluetooth, Cast, голос, температурную защиту, вентилятор, сон/автовыключение и OTA. Отдельную «регулировку оборотов вентилятора» не добавлять. **3D не добавлять вообще:** на данном проекторе владелец её не обнаружил.

## Ручная проверка после отдельной установки обычного подписанного APK

1. Без изменения HOME открыть FreeMyProjector → «Настройки» → «Функции проектора», пройти 6 разделов стрелками/OK/Back. Длинные названия должны помещаться; фокус не должен теряться.
2. Открыть, но **не изменять параметры** «Фокусировка», «Коррекция трапеции» и другие OEM экраны. **Не нажимать авто-калибровку.**
3. Проверить, какой пункт ведёт в конкретный заводской экран, а какой — в общие Settings. Собрать только названия/пути, без серийного номера/IP и без отправки APK прошивки.
4. Убедиться, что родные кнопки Home/Back/Power, сопряжение, оптика, звук, HDMI, Wi-Fi и заводские настройки остаются доступными после возвращения из нашего приложения.

Запреты не изменены: `ModeJob.PROJECTOR_HOME_SWITCH_AUDITED=false`, никакого ADB-write, disabling OEM, firmware flash, автосопряжения или автоматического пробного переключения HOME.
