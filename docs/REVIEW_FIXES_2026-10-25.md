# Аудит ревью 25.10.2026: решения и очередь безопасных PR

Источник: пользовательское ревью `FreeMyProjector_REVIEW_2026-10-25.md` по устаревшему main `4caf7b8`. Текущий main после PR #35/#36 отличался: `v0.1.1` ещё не выпускался; HomeActivity/HomeReceiver/RemoteKeyService уже **disabled в AndroidManifest** с бинарными CI-checks.

## Результаты сверки

| Замечание | Статус | Действие |
|---|---|---|
| HOME resolver при установке обычного APK | **Уже исправлено** в PR #35 | HomeActivity Android `enabled=false`, verified compiled manifest. Не нужен отдельный activity-alias в preview. Снятие блокировки — отдельный пилот после P-04F. |
| Debloat/PM disable штатных пакетов из HomeMode.applyFree/verifyNow | **Дефект исходного кода** | P-04R первый PR: удалить исполняемые ветки disable, package enable и любые экранные/заставочные автоматические операции. Ни один установленный APK не трогаем. |
| False success при chooser/fallback и Android9 cmd role | **Дефект исходного кода** | P-04R: exact `com.google.android.tvlauncher/.MainActivity` (normalizing shorthand), user0, модель/build, package present+enabled, проверенный результат. В случае chooser/fallback/unknown — STOP, никакой записи. Не использовать `cmd role`. |
| REVERT блокируется вместе с APPLY | **Точный факт** | P-04R: добавить **независимый** `PROJECTOR_RECOVERY_AUDITED=false` и action-level policy. Пока обе операции запрещены; 'REVERT всегда разрешён' отклонено, поскольку позволяет менять HOME на нетестированном устройстве. |
| Заставка против таймера сна | **Физический тест отсутствует** | P-04R не меняет штатную заставку, поэтому до будущего HOME-пилота штатный сон не затрагиваем. P-07 отдельный read-only/ручной тест после теста APK. |
| ADB порт 5555 | **Сетевая поверхность риска** | Считать localhost-соединение с TCP ADB не доказательством изоляции. Не включать и не оставлять TCP debugging как автоматическое последствие теста; проверить состояние в read-only безопасной диагностике, рекомендации владельцу после пилота. |
| HDMI через Live TV intent | **Технический риск; не аппаратный баг, пока не проверено** | Потребуются диагностика точного `TvInputInfo` и OEM activity на .4185; не «исправлять» гипотезу опасной командой включения источника. Отдельный PR P-06H и ручная проверка. |
| Прямой быстрый фокус и трапеция | **Нужно, но опасно запускать до OEM аудита** | Прямой `FocusActivity`/`KeystoneActivity` заблокирован в P-05 `P05_DIRECT_OPTICS_AUDITED=false`; возможны безопасные быстрые переходы к общему OEM меню. |
| Кнопка возврата HOME без ADB | **Условно** | Не включать system chooser/чужую роль в P-05. Вместо этого можно добавить справочную кнопку/проверенное открытие обычных системных Settings; настоящий механизм восстановления — P-04F/P-04I. |
| Кнопка питания/сна | **Функция есть в прошивке** | Только ярлык на заводской раздел питания или штатную физическую кнопку, без произвольного `KEYCODE_POWER` через ADB или вызова HAL. |
| Secret scanning и push protection | **Полезно** | Текущий GitHub repo публичный (GitHub API); настройка через GitHub Security владельцем, если доступны соответствующие права/план. Проверка ревью не доказывает будущего отсутствия утечек. |
| Пароль в локальном .txt рядом с ключом | **Риск по сообщению автора ревью** | Владелец переносит пароль в менеджер, проверяет backup, безопасно удаляет local .txt; **не передавать пароль/keystore в GitHub или чат**. Ничего удалённо не удалять. |
| CRLF / локальный `git pull` | **Указание ревью для локального ПК** | Рекомендовать `git pull --ff-only origin main` только если рабочая копия чистая; не запускать на ПК пользователя через GitHub. |

**Проверено на GitHub:** репозиторий на момент просмотра публичный; значит указанная в ревью оговорка «если сделать публичным» уже не гипотетическая. Личная локальная текстовая запись пароля и фактическая настройка TCP ADB удалённо не проверены. [P-04S: секреты, ADB, сон](P04S_ADB_SECRETS_SLEEP_SECURITY.md).

## Очерёдность

1. **P-04R** — убрать опасные будущие HomeMode операции, строго проверять rollback, отдельная, пока закрытая recovery gate; CI и документация. *Не изменяет проектор*.
2. **P-06H** — read-only аудит HDMI passthrough и OEM открытий (без смены источника), безопасный UX fallback; отдельная матрица и тесты.
3. **P-06Q** — в код будущего HOME drawer добавлены **«Оптика» и «Питание»**: первое открывает общий OEM экран через P-05 optics guard, второе — заводские настройки питания; ни одна кнопка не фокусирует, не калибрует, не отправляет power/sleep keyevent. HOME в `v0.1.1` по-прежнему выключен. **Настоящая кнопка возврата штатного HOME пока НЕ реализуется**, поскольку системный выбор HOME без проверенного ADB/аппаратного восстановления опасен.
4. **P-07** — сон/перегрев/ADB network exposure и фактическая проверка после подписанного preview. **30-минутный watchdog** остаётся исследованием и mock-only до аппаратной проверки.
5. **Release v0.1.1** — вручную из main после зелёных PR и согласия владельца, **с той же подписью**, как обычный APK. Ни CI, ни PR ничего не устанавливают.
