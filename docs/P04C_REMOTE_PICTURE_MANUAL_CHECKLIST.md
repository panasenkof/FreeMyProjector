## Сценарий ручной проверки без сброса и изменений

Работать только в **штатном заводском интерфейсе**. На данном этапе **не запускать** FreeMyProjector в HOME-режиме, не проводить сброс Bluetooth, не удалять сопряжение, не выполнять автокалибровку, заводской сброс, перепрошивку и изменения настроек проекции.

| ID | Наблюдение | Ожидаемое подтверждение владельца |
| --- | --- | --- |
| R-01 | Обычные стрелки, OK и Back комплектного пульта | Навигация и выход из меню работают |
| R-02 | Кнопка HOME | Возврат к Google TV Launcher; штатные настройки доступны |
| R-03 | Кнопка шестерёнки / Настройки | Какая именно страница открывается; не менять параметры |
| R-04 | Одиночные и длительные нажатия громкости | Есть ли авто-повтор, особые функции, зависания; затем вернуть обычную комфортную громкость |
| R-05 | Микрофон / голос, если физически доступен | Реакция штатной системы; не диктовать личные сведения |
| R-06 | Сон / пробуждение штатной кнопкой | Пульт остаётся доступным; переподключение происходит само (холодный старт пока не нужен) |
| R-07 | В системных настройках найти пункт сопряжения пульта | Зафиксировать путь в меню и отображаемый тип подключения, **не отключать и не переподключать** |
| R-08 | Независимый способ управления (например USB-клавиатура, если есть) | Проверить, что стрелки/Enter/Escape могут открывать/закрывать штатные меню без HOME-модификации; не считать наличие USB порта гарантией работы |
| I-01 | Открыть штатное «Изображение» | Названия пунктов, текущий «Режим изображения», все видимые значения; ничего не изменять |
| I-02 | Пункт про яркость камеры | Точное название и пояснение (если есть); **не считать это регулировкой яркости лампы** |
| O-01 | Найти штатную страницу фокусировки | Открывается и может быть закрыта без изменений; ручная/автофокусировка как наличие пунктов — не аппаратный тест |
| O-02 | Найти страницу коррекции трапецеидальных искажений | Открывается и закрывается; отметить наличие авто-коррекции и отдельной калибровки; **не запускать калибровку** |
| H-01 | В меню открыть список входов/HDMI (если вход используется) | Можно попасть в штатный список и вернуться HOME; не менять источник, если нет подключения |
| P-01 | Как именно восстанавливать сопряжение при сбое | **Только выяснить инструкцию/путь и доступный резервный ввод**; фактическое разъединение/повторное сопряжение делать в отдельном согласованном тесте после доказанного альтернативного управления |

Для каждого пункта записать `работает / не работает / не проверено`, при наличии — фактическое поведение. Не угадывать кнопки и комбинации. Если действие предлагает *изменить* фокус, калибровку, сопряжение, сброс, HOME или другую OEM настройку — **отменить**.

## Что делать с результатами

Прислать в чат **только итоги наблюдений** по ID и при необходимости фото страницы меню без идентификаторов/личной информации. Фотографии и остальные локальные диагностические материалы хранить **в родительском каталоге** `D:\Git\FreeMyProjector`, а не внутри Git.

После получения результатов:
1. Установить, нужен ли независимый резервный ввод перед проверкой повторного сопряжения.
2. Разработать **офлайн mock-модель** Android 9 для будущего отката и проверить сценарии отказа.
3. Лишь после отдельного разрешения и проверенного плана восстановления рассматривать установку обычного APK (не HOME); HOME-switch запрещён.

**Не меняем** `ModeJob.PROJECTOR_HOME_SWITCH_AUDITED=false`, не вводим adb-write команды. Успех этой ручной проверки сам по себе не снимает P0-ограничения и не заменяет backup firmware/calibration.
