# MiProjM05 — матрица заводских функций (исследование 25.10.2026)

**Наблюдение владельца 25.10.2026:** все ранее исследованные функции, **кроме 3D**, действительно есть на его MiProjM05. Это свидетельство наличия возможностей, а не точная инвентаризация подменю, значений и exported Activity. **3D отсутствует по наблюдению владельца и не включается в наши настройки.** [Реализация каталога P-06](P06_NATIVE_PROJECTOR_SETTINGS.md).

**Аппаратный baseline:** MiProjM05/eva, Android TV 9 API 28, сборка PQ3B.190705.003.4185. Товарные идентификаторы MJJGTYDS02FM/M055MGN в официальных руководствах не подтверждены наклейкой владельца. **Не обещать функцию до подтверждения конкретной прошивки**.

### Уточнения из официальных материалов

1. FAQ Xiaomi: **инфракрасный пульт не поддерживается**, так что IR не является аварийным способом управления.
2. PDF Quick Start Guide описывает для сопряжения кнопки **Return + App**, FAQ **Home + Menu**. Это расхождение; сочетание нужно определять по фактическому пульту и **не инициировать переподключение** ради эксперимента.
3. **3D исключён по ответу владельца**; Bluetooth audio и режимы установки/проекции присутствуют по сообщению владельца, но точные вложенные пути в `.4185` ещё не записаны.
4. FreeMyProjector не заменяет прошивку: предпочтительны прямые безопасные переходы в OEM меню с проверкой exported/permission, с fallback «Все настройки», OEM пакеты остаются включёнными.

### Дальнейшие этапы

- P-04H: только read-only выявление точного компонента сопряжения через ADB на .4185; безопасный ручной переход через Settings.ACTION_BLUETOOTH_SETTINGS с fallback к общим Settings.
- P-04I: PC-first одноразовый watchdog для испытания HOME: 30 минут по желанию владельца (предпочтительный тестовый интервал 5–10 мин), **ручное подтверждение с пульта** отменяет только после фиксации результата, при отсутствии ADB отчёт о невозможности возврата. Не гарантия при потере сети/питания.
- P-05: первое открытие подписанного APK как обычного приложения без смены HOME после согласования.
- P-06: [разделы и безопасные системные переходы добавлены в исходники](P06_NATIVE_PROJECTOR_SETTINGS.md); **автоматические аппаратные действия запрещены**, CI и реальный пользовательский тест обычного APK ещё различать.
