## Что можно позаимствовать архитектурно, по приоритетам

### P0 / P-04 — безопасный откат с точным состоянием

В \`tools/recovery.py\` CleanYourTV сохраняется запись **до первого изменения**: component HOME, original enabled/disabled/absent для каждого затрагиваемого пакета, некоторые системные настройки. Повторное применение не перезаписывает «оригинал» уже изменённым состоянием. Restore не включает приложения, которые были отключены до очистки. У нас эта идея лучше универсального \`pm enable\`, поскольку нужен проверяемый откат на точной конфигурации. **Пока только проектировать, не запускать на устройстве.** Создать спецификацию snapshot + проверка изменений + симуляция восстановления в тестах.

Дополнительно полезны проверки \`Home guard\`: исключать \`FallbackHome\`, factory-test HOME и любые неподходящие активити из кандидатов для отката; проверять не только успешный ответ \`set-home-activity\`, но и фактическое разрешение HOME после него. Особенно важно на Android 9: \`cmd role\` может быть неподходящим механизмом.

### P0 / P-04A — OEM, HDMI, автоматическая калибровка

Защищать \`com.droidlogic.*\` только после идентификации реальных пакетов/служб; как минимум рассмотреть \`com.droidlogic.tvinput\`, \`com.formovie.fmutils\`, \`com.formovie.gsettings\`, \`com.formovie.launchboard\` в целевом проекте. Уже есть защита всех \`com.fengmi.*\`, \`com.formovie.*\`, \`cn.formovie.*\`. При любой будущей операции отключения вводить общий safety check \`android.permission.TV_INPUT_HARDWARE\`, чтобы не потерять видео HDMI/AV. До завершения P-04 не отключать **вообще ничего**, даже telemetry/Camera2.

Нужна раздельная проверка: ручная фокусировка, автофокус, ручная коррекция, автоматическая коррекция, автоматическая калибровка, смена входа HDMI, голосовое управление, кнопки пульта. Фото меню доказывает лишь наличие элементов.

### P1 / P-06 — кнопки в своей оболочке без новой аппаратной логики

На первом этапе открывать штатные **явно подтверждённые** Activity настроек Xiaomi/Fengmi; не запускать найденные в сети неизвестные focus/keystone Intent. Использовать штатный \`TvInputManager\` для отображения доступных входов после теста на нашей прошивке. Кнопку с шестерёнкой сначала исследовать без перехватчика (KeyEvent/logcat для пульта); отдельный сервис переназначения клавиш — последняя опция из-за регрессии Volume Up в другом проекте.

### P1 / P-07 — измеримые регрессии

Позаимствовать **методику**, не скрипты автоматически: p50 возврата HOME, cold start, задержка реакции на D-pad, jank, PSS, idle CPU; сравнивать на одной прошивке и с одинаковыми условиями. У CleanYourTV есть \`tools/bench.py\`, \`tools/trace.py\`, \`tools/screendiff.py\`, тесты Home guard / recovery / HDMI safety. Переносить точечно через отдельные спецификации с тестами Android 9.

### P1–P2 / после первого безопасного пилота

Идеи отдельных кнопок/модулей для источников (\`addons/sources\`), схемы необязательных модулей (off by default), темы и измерения UI-производительности могут пригодиться для интерфейса пульта. Не добавлять фоновые сервисы, accessibility и OVERLAY как предпосылку сохранения оптики. Не относится к ускорению YouTube напрямую.

## Важные чужие сбои: против каких ошибок пишем тесты

- \`set-home-activity\` сообщал Success, но заводской лаунчер оставался HOME либо открывался FallbackHome (истории других Xiaomi / Google TV). Это не обязательно воспроизводится на eva.
- На некоторых устройствах после отключения пакетов пропадали HDMI («No Signal» при видимом кабеле), Wi-Fi или нормальный запуск HOME; наличие ADB по сети не гарантирует восстановления.
- Изменение набора приложений, объявляющих HOME, может сбрасывать выбор пользователя, а OTA или перезагрузка — переактивировать системные пакеты.
- Helper для аппаратной кнопки Settings у автора MiProjM05 привёл к нарушению удержания громкости; эту регрессию надо включить в приёмочный тест.

## Следующие исследования на нашей прошивке — только чтение

1. Проверить присутствие \`com.droidlogic.tvinput\`, \`com.formovie.fmutils\`, \`com.formovie.gsettings\`, \`com.formovie.launchboard\` вместе с Fengmi через отфильтрованный \`pm list packages\`. Не публиковать полный перечень или приватные поля.
2. Локально изучить только найденные \`dumpsys package\`: нужные Activity и сервисы, intent-filters, разрешения \`TV_INPUT_HARDWARE\`. Не запускать их без отдельного согласования.
3. Зафиксировать реальные события шестерёнки и удержания громкости **без назначения/перехвата** клавиш.
4. Руками в заводском HOME проверить штатные оптические функции и HDMI; не менять сохранённые заводские значения калибровки.
5. Для P-04 подготовить проект восстановления с backup actual enabled-state/HOME; писать тесты и проверять static safety guard. Только после отдельного одобрения владельца — действия с HOME.

**Статус по проекту:** изучение источника завершено, исследовательские гипотезы внесены; аппаратная верификация новых компонентов на \`.4185\` не проведена. Запрет \`ModeJob.PROJECTOR_HOME_SWITCH_AUDITED=false\` сохраняется.
