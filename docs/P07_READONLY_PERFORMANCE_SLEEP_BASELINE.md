# P-07 — безопасная базовая проверка ресурсов и сна MiProjM05

**Дата:** 25.10.2026. **Статус:** протокол подготовлен; измерения на проекторе не проводились. Не является разрешением на установку APK, смену HOME или изменение настроек.

## Назначение

Сравнить ресурсы и штатное поведение проектора **до** и **после** отдельной, разрешённой владельцем установки preview APK v0.1.1. Измерения должны отделять эффекты приложения от фоновых задач Android TV и сетевой активности. Тестировать производительность будущего HOME преждевременно: `HomeActivity` отключена.

## Ворота безопасности

1. До измерений проверить соответствие `MiProjM05/eva`, Android 9 / SDK 28, build `PQ3B.190705.003.4185`, active user 0 и заводской HOME `com.google.android.tvlauncher/.MainActivity` с сохранённым снимком P-04B. При расхождении **STOP**.
2. Использовать только чтение `adb shell getprop`, `dumpsys`, `cat /proc/meminfo`, `top` (если поддерживается), `pm list packages`. Не использовать `settings put`, `pm disable`, `cmd package set-home-activity`, `input keyevent`, `adb tcpip`, `reboot` или команды остановки служб.
3. Никакой установки APK, назначения HOME, запуска прямых Focus/Keystone и автокалибровки в рамках этого протокола. P-05 выполняется отдельно по согласию владельца.
4. Ничего не публиковать в репозиторий из необработанного вывода `dumpsys`/`logcat`: там могут быть IP, MAC, serial, имена устройств, пользовательские данные и токены. Публиковать только агрегаты после очистки.
5. Не проводить длительных нагрузочных тестов с повышением температуры. При предупреждении системы о перегреве или ненормальном шуме прекратить эксперимент штатным способом.

## Предварительный базовый замер (до установки)

* Записать вручную: дата/время, заводской HOME, режим питания, включён ли сетевой доступ, есть ли HDMI-сигнал, температура помещения по желанию.
* После обычного простоя записать минимум три независимых выборки с сопоставимыми условиями. Между выборками выдержать одинаковый интервал, фиксируя его в журнале.
* Метрики: `MemAvailable` и `MemTotal` из `/proc/meminfo`; CPU utilization только при корректной доступности `top`/дельта-счётчиков; RAM процесса FreeMyProjector (только **после** установки) из `dumpsys meminfo com.fader.freemyprojector`; устойчивость пульта; успешность возврата в заводской HOME.
* Время запуска/FPS без подготовленного измерителя **не оценивать на глаз и не выдавать за численный результат**. Если источник температуры от OEM недоступен, отмечать `not available`, не придумывать значения.
* Сон/пробуждение: только штатным пультом/через заводское меню; зафиксировать наблюдение работы лампы и возврата к штатному экрану. Никаких ADB-команд выключения.

## Отдельный тест preview (только после разрешённого P-05)

* Установить **подписанный** v0.1.1 с прежним ключом вручную по протоколу P-05; не устанавливать unsigned и не изменять HOME.
* Повторить три выборки в эквивалентных условиях: (а) штатный HOME, приложение закрыто; (б) открытые Settings FreeMyProjector; (в) после выхода Back в штатный HOME.
* При зависании прекратить тест, а не включать неаудированную ветку recovery. Зафиксировать версию, наблюдение, шаг и возможность обычного выхода.
* Перед выводом «регрессия» повторить наблюдение и сравнить разброс исходных выборок. В отдельной спецификации согласовать пороги по памяти/CPU/времени, основанные на собранной базе, а не произвольные проценты.

## Формат итогового обезличенного отчёта

| Поле | Допустимое значение |
| --- | --- |
| model / build | `MiProjM05` / `PQ3B.190705.003.4185` |
| phase | `stock-before`, `preview-stock-home`, `preview-settings`, `preview-after-back` |
| samples | количество реально полученных наблюдений |
| mem_total_kib / mem_available_kib | числовые агрегаты, если доступны |
| app_pss_kib | только после установки, иначе `not available` |
| cpu / temperature / fps | измеренное с указанным источником либо `not available` |
| stock_home_unchanged | `true/false/unverified` |
| remote / sleep | текст наблюдения, без личных данных |
| device_writes | `0` для базового чтения; отдельно документировать разрешённую установку APK |
| conclusion | `baseline-only`, `needs-hardware-retest`, `regression-confirmed` |

## Пробный сборщик P-07 (пока не аппаратно проверен)

После слияния кода и лишь при готовности выполнить чтение с локального ПК:

```powershell
.\tools\Measure-ProjectorMemoryReadOnly.ps1 -SnapshotDirectory $folder -AdbPath $adb -Phase stock-before
```

Команда только читает RAM при совпадении P-04E user0/baseline и активном заводском HOME. Для стадий после отдельно разрешённой установки APK использовать `-Phase preview-stock-home`, `preview-settings` либо `preview-after-back`; скрипт не устанавливает APK. Вывод содержит единственную выборку. `app_pss_kib` может остаться `null`, если `dumpsys` не даёт однозначный формат. CPU, FPS и температура не измеряются, а сон наблюдается вручную. Нужны как минимум три раздельные выборки в сопоставимых условиях; не интерпретировать один замер как регрессию.

Статические тесты: `python -m unittest discover -s tools/ci -p 'test_p07_readonly_probe.py'`. Они не заменяют выполнение PowerShell с mock ADB на Windows и реальную проверку на проекторе.
