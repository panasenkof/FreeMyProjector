# Локальные файлы FreeMyProjector в Windows

**Рабочая папка владельца:** `D:\Git\FreeMyProjector`.

Разделение источников и приватных артефактов обязательно:

```text
D:\Git\FreeMyProjector\
├── FreeMyProjector-main\               # Git-копия: исходники, docs, tools, tests
│   └── .git\                           # История и связь с GitHub
├── MiProjM05-baseline-20261025-...\    # Приватные снимки; по одному каталогу на запуск
│   ├── baseline.private.json
│   └── SHA256SUMS.txt
├── MiProjM05-imaging.apk               # Если скопировали OEM APK: хранить только локально
└── ...                                 # Прочие локальные диагностические результаты
```

`MiProjM05-baseline-20261025-...` здесь — **пример имени**, не команда создавать или переименовывать файл.

## Правило по умолчанию

Исходный код, инструкции и тесты — **в Git-репозитории** `FreeMyProjector-main`; локальные снимки, APK, диагностические выводы и фото — **в родительской папке**, но **не внутри Git-репозитория**, чтобы случайно не опубликовать приватные данные.

Начиная с P-04B, `tools/Save-ProjectorBaseline.ps1` автоматически использует **родительскую папку своей Git-копии**, поэтому для такой структуры сохраняет снимки в `D:\Git\FreeMyProjector`. Явное `-OutputDirectory` по-прежнему разрешено для другой папки **вне Git-репозитория**.

```powershell
cd D:\Git\FreeMyProjector\FreeMyProjector-main
git pull --ff-only origin main
.\tools\Save-ProjectorBaseline.ps1 -AdbPath $adb
```

Создаётся **новая** папка `MiProjM05-baseline-...` рядом с `FreeMyProjector-main`, предыдущая не затрагивается. Приведённая команда — только для чтения с устройства. HOME, калибровки и пакеты не изменяются.

### Снимок уже перенесён владельцем

25.10.2026 владелец сообщил об успешном read-only сборе: `status=saved`, `packages=114`, `disabled_packages=0`, затем перенёс каталог снимка в `D:\Git\FreeMyProjector`. Это означает, что снимок текущих **состояний пакетов/HOME** существует локально, **не полный образ прошивки**. Целостность после перемещения **успешно проверена владельцем 25.10.2026** по SHA256 (`verified`, `match`). Сверка с текущим проектором также пройдена (`matches-baseline`, 114/114 пакетов, исходный HOME без изменений), без приватного JSON в GitHub.

```powershell
# Подставь имя своей папки, если оно изменится.
$folder = 'D:\Git\FreeMyProjector\MiProjM05-baseline-20261025-091132-80cc72ea6d'
$expected = ((Get-Content (Join-Path $folder 'SHA256SUMS.txt') -First 1) -split '\s+')[0]
$actual = (Get-FileHash (Join-Path $folder 'baseline.private.json') -Algorithm SHA256).Hash
$actual -ieq $expected   # Ожидается True
```

Если получили `False`, не используйте снимок для отката, сначала выясните причину.

## Другие результаты

- **OEM APK:** если `MiProjM05-imaging.apk` раньше копировали в `$env:TEMP`, можно переместить вручную в `D:\Git\FreeMyProjector`. Не заменять имеющийся файл вслепую, не публиковать APK на GitHub.
- **Диагностика P-01:** `tools/read-only-device-info.ps1 -OutputPath 'D:\Git\FreeMyProjector\device-info.local.json'` (обычно JSON безопасен для вывода, но личные диагностические файлы всё равно держать вне Git).
- **Фотографии пульта, оптики, настройки изображения:** хранить под `D:\Git\FreeMyProjector` и отправлять только изображения без личных данных.
- **Резервные схемы отката, если будут созданы:** сохранять локально туда же, перед их запуском проверять содержимое и отдельные условия безопасности.

**Не нужно перемещать** Git-репозиторий, файлы Windows/Android SDK, исполняемые инструменты, временные файлы сборки или вручную изменять устройство. Единая папка относится к **данным и результатам работы над FreeMyProjector**, а не ко всему ПО компьютера. Никакой локальный путь на компьютере владельца невозможно изменить одним PR: после обновления Git будет действовать новое поведение скрипта.

Пока остаётся заблокированной смена HOME: `ModeJob.PROJECTOR_HOME_SWITCH_AUDITED=false`. Тесты пульта/повторного сопряжения, картинки и реального восстановления обязательны.
