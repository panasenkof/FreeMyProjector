# P-04E — проверка области пользователя Android 9 (только чтение)

**Почему:** на Android приложение может быть включено для одного пользователя и отключено для другого. Для восстановления недостаточно знать только названия 114 пакетов. Android Open Source Project подтверждает, что `adb shell pm list packages --user 0` с `-e` и `-d` запрашивает конкретного пользователя. Ссылка: https://source.android.com/docs/devices/admin/multi-user-testing ; реальную поддержку на MiProjM05/.4185 ещё предстоит проверить.

**Уже проверено 25.10.2026:** настоящий baseline (114 пакетов, 0 отключённых) совпадает с HOME и состояниями проектора. P-04D офлайн-тест с этим снимком завершён `passed` во всех 5 сценариях. Это не доказывает реальный откат.

## На Windows после зелёного CI и слияния PR

```powershell
cd D:\Git\FreeMyProjector\FreeMyProjector-main
git pull --ff-only origin main
$folder = 'D:\Git\FreeMyProjector\MiProjM05-baseline-20261025-091132-80cc72ea6d'
.\tools\Test-ProjectorUser0Scope.ps1 -SnapshotDirectory $folder -AdbPath $adb
```

Если `$adb` не задан в текущем терминале, используй ранее проверенный путь к adb.exe. Скрипт:
- сначала проверяет SHA256 локального снимка **до любого ADB**;
- требует единственный авторизованный MiProjM05/eva с точной Android 9 .4185;
- читает `am get-current-user` и останавливается, если активный пользователь не 0;
- только читает обычные `pm list packages`, `-e`, `-d` и их варианты с `--user 0`;
- сверяет полноту каждого набора и проверяет важные OEM-пакеты;
- возвращает **только агрегированные числа**, без serial/IP, имён приложений или записи файлов.

Результат `user0-matches-baseline` означает лишь совпадение явной, неявной и сохранённой выборок имён/состояний пакетов на текущей прошивке. `review-required` требует отдельно изучить расхождения, ничего не исправляя. Ошибка `P-04E read-only scope STOPPED` — неизвестная или небезопасная ситуация; НЕ обходить проверки.

Команда не включает, не выключает и не устанавливает приложения, не меняет HOME, пульт, HDMI, фокусировку или прошивку. Старый снимок не изменяется и **не объявляется резервной копией user 0 задним числом**. `ModeJob.PROJECTOR_HOME_SWITCH_AUDITED=false` остаётся без изменений.

Даже успешная проверка user 0 **не является реальным тестом отката**. Нужны отдельно подтверждённый независимый аварийный доступ, проверка кнопок и OEM-оптики, процедура восстановления Android 9 с журналом наших изменений и отдельное согласие владельца на системный пилот. См. [P-04D](P04D_OFFLINE_ROLLBACK_SIMULATION.md) и [общий протокол](MIPROJM05_BACKUP_REMOTE_PICTURE_ROLLBACK.md).
