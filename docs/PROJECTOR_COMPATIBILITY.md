# FreeMyProjector — проверка совместимости и план адаптации

## Устройство (предварительно)
- **Предполагаемая модель:** Xiaomi Mi Smart Compact Projector, `MJJGTYDS02FM` (по скриншоту заказа).
- **Документированные Xiaomi характеристики:** Amlogic T962-X, 2 ГБ ОЗУ, 16 ГБ памяти, Android TV 9.0, Full HD 1080p.
- **Точный вариант прошивки ещё не подтверждён**: проверить в настройках самого устройства до установки.
- Источник спецификаций: https://www.mi.com/ru/mi-smart-compact-projector/specs/

## Происхождение исходников
Основа — https://github.com/simbasjungles/free-my-tv , лицензия MIT.
Снимок исходников и контрольная ревизия указаны в корневом `UPSTREAM.md`. Обновления из исходного проекта не применяются автоматически. Отсутствует лишь upstream workflow публикации чужого сайта (он для проектора не нужен).

## Принципы разработки
1. **Безопасная обратимость:** штатный интерфейс должен быть доступен даже при неполадках нашей оболочки. Не удалять системные пакеты без отдельного согласования.
2. **Без root по умолчанию:** начать с обычной установки APK и диагностики через ADB.
3. **Android TV 9 и слабое железо:** не добавлять тяжёлые фоновые службы; измерять память, время запуска и отзывчивость на пульт.
4. **Отдельная идентичность приложения:** перед первой сборкой адаптации определить package name, название, иконку и ключ подписи; не допустить случайного обновления чужого приложения.
5. **Никаких секретов в Git:** ключи TMDB, VPN, прокси и приватные адреса — только в локальной конфигурации/секретах.
6. **Отдельные Pull Request:** доработки и обратные синхронизации с оригиналом проходят ревью.

|---|---|---|
| P0 | Зафиксировать upstream и лицензию | Содержимое ветки импорта проверено по SHA Git-объектов |
| P0 | Подтвердить модель, прошивку и версию Android TV | Данные из «О проекторе» + диагностика без изменения настроек |

| P0 | Проверить безопасный возврат на родной экран | Выключение/сбой оболочки не блокирует проектор |
| P1 | Настроить оболочку для Xiaomi и оптимизировать производительность | Главный экран, фокус пульта, сон/пробуждение/перезагрузка |
| P1 | Исследовать запуск YouTube и сетевые ограничения в РФ | Измерить фактическую доступность; отделить сетевую проблему от производительности |
| P2 | При необходимости добавить управляемую настройку прокси/VPN или интеграцию с роутером | Работает только по явному выбору; есть отключение; нет секретов в репозитории |

**Важно:** замена лаунчера не ускоряет YouTube сама по себе. Для проблем с сетью потребуется отдельное исследование и решение. Эффект не гарантирован.

## Безопасная первичная диагностика

На проекторе открыть **Настройки → Об устройстве** и записать модель, сборку и версию Android.

При разрешённой ADB-диагностике использовать только команды чтения:

```sh
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
adb shell getprop ro.build.fingerprint
adb shell pm list packages
```

Не отключать системный launcher, не удалять Wi-Fi-профили, не применять команды из чужих инструкций без отдельной проверки на этой модели.
