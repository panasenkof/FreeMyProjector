# Xiaomi MiProjM05: как сохранить фокусировку и коррекцию трапеции

**Статус:** 24.10.2026 — план исследования, на реальном устройстве ещё не проверено. Системная модель `MiProjM05`, Android 9, сборка `PQ3B.190705.003.4185`.

## Решение по архитектуре

**Оставляем заводскую прошивку, заменяем только домашний экран**, когда P-04 подтвердит безопасность. Штатные настройки, службы, оптические драйверы и приложение Xiaomi должны оставаться установлены и доступны. Смена HOME в одиночку не гарантирует сохранность функций, если она одновременно отключит нужный системный пакет.

Целевые функции: автофокус, ручная фокусировка, **вертикальная коррекция трапеции**, HDMI/режимы проекции, пульт, заводские настройки и возврат к заводскому HOME. Официальная спецификация именно Mi Smart Compact Projector указывает только *Vertical keystone correction*: автокоррекция или 4-точечная коррекция не доказаны и не должны обещаться до проверки в меню конкретной прошивки. Источник: https://www.mi.com/global/product/mi-smart-compact-projector/specs/

## Поиск на устройстве (не меняет настройки)

1. До изменений проверить фокусировку и трапецию через заводское меню, сделать фото только экранов настроек (не серийного номера). Проверить результат без Интернета.
2. При наличии разрешённого ADB воспользоваться `tools/read-only-device-info.ps1` по `docs/DEVICE_DIAGNOSTICS_WINDOWS.md`. Подключение опционально, root не нужен, IP/серийный номер в Git или чат не отправлять.
3. На своём компьютере выполнить **только чтение**: `adb shell pm list packages`. В списке искать `fengmi`, `xiaomi`, `projector`, `focus`, `keystone`, `mitv`, `miui`, `settings`. **Имя не доказывает назначение.** Не выкладывать полный вывод.
4. Для найденного пакета `adb shell pm path <PACKAGE>`, `adb shell dumpsys package <PACKAGE>`. Изучить локально его компоненты, Intent filters и разрешения; в публичном отчёте оставить только найденные имена Activity/Service и действия без приватных полей. Команды `pm disable-user`, `am start`, `cmd package set-home-activity` и `settings put` **пока запрещены**.
5. Проверить, какие именно приложения и сервисы нужны для обеих функций. Внести их в `HomeMode.PROTECTED` и дополнительный fail-closed сценарий P-04. Новые компоненты не угадывать по названию бренда.
6. На первом этапе выводить из FreeMyProjector **штатные экраны Xiaomi**, а не писать собственный драйвер мотора. Перед первым запуском любых Intent на реальном проекторе согласовать сценарий и rollback.

**Важно:** у проекта Free My TV появилась поддержка HY300 через `action.htcsettings.prjsettings`, но HY300 — другой проектор, это не команда для Xiaomi. В интернете встречается `com.fengmi.projector.imaging.action.START_FOCUS` для других устройств Xiaomi/Fengmi; для `MiProjM05` действие **не подтверждено** и автоматически вызывать его нельзя.

## Если потребуется reverse engineering

После определения точного пакета команда `adb pull <READABLE_APK_PATH> <LOCAL_FILE>` может скопировать доступный APK с проектора на ПК без изменений на проекторе; разрешения Android могут помешать. Для **локального** анализа — `apkanalyzer`, `jadx`, `apktool`: AndroidManifest, активности, разрешения, сервисы, Binder и JNI. Не публиковать оригинальные APK, закрытые библиотеки или DRM-материалы.

Официальный OTA-файл (если доступен именно для модели и версии) может быть инкрементным и не содержать полного firmware. Снять **полную** прошивку без привилегий часто нельзя; root, перепрошивка и разблокировка загрузчика несут риск потери калибровки/работоспособности. Не выполнять их на этом этапе. Даже изученное штатное приложение может пользоваться `signature|privileged` разрешениями, поэтому полностью заменить его обычным приложением нельзя без OEM-интеграции.

## Критерии приёмки до P-04/P-05

- Подтверждены реальные компоненты, необходимые для автофокуса, ручного фокуса и штатной **вертикальной** коррекции трапеции на MiProjM05.
- Режим по умолчанию ничего не отключает, список protected расширен на основании evidence.
- Доступ к обеим оптическим функциям проверен **без изменения HOME**.
- Известен рабочий способ возврата в заводские настройки и оригинальный HOME, включая проверку после перезагрузки.
- CI и эмулятор не считаются доказательством работы на реальном проекторе.
