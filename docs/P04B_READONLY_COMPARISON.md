# P-04B — безопасная проверка baseline и просмотр расхождений

**Функция:** `tools/Compare-ProjectorBaseline.ps1`. Она проверяет сохранённый снимок MiProjM05/eva с прошивкой `PQ3B.190705.003.4185` и **только читает** текущее состояние проектора. Команд изменения HOME, пакетов, калибровки, настроек изображения, Bluetooth и прошивки в ней нет. Это **не инструмент восстановления**; фактический откат потребует отдельного согласования.

## Где лежат файлы

Единая рабочая папка: `D:\Git\FreeMyProjector`.
- `FreeMyProjector-main\` — Git-репозиторий.
- `MiProjM05-baseline-20261025-091132-80cc72ea6d\` — локальный снимок от 25.10.2026 (114 пакетов, 0 disabled).
- `MiProjM05-imaging.apk` — **один** заводской APK, только локально.

**Не перезаписывать исходный снимок.** Не публиковать в GitHub / чат `baseline.private.json`, полный список личных приложений, MAC, IP, серийные номера и APK.

## Этап A. Проверка SHA-256 без подключения проектора

После обновления Git из Windows PowerShell:

```powershell
cd D:\Git\FreeMyProjector\FreeMyProjector-main
$folder = 'D:\Git\FreeMyProjector\MiProjM05-baseline-20261025-091132-80cc72ea6d'
.\tools\Compare-ProjectorBaseline.ps1 -SnapshotDirectory $folder -VerifyOnly
```

При успехе статус `verified`, `sha256=match`, `device_access=none`. Результат только в консоли, новый снимок не создаётся. Любая ошибка контрольной суммы, схемы или полей останавливает работу ещё до обращения к ADB.

SHA-256 защищает от случайной порчи файла при перемещении. Если злоумышленник мог заменить и JSON, и SHA256SUMS, проверка **не доказывает** подлинность архива.

## Этап B. Сравнить с живым проектором без изменений

Только после успешного этапа A:

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
.\tools\Compare-ProjectorBaseline.ps1 -SnapshotDirectory $folder -AdbPath $adb
```

Допускается ровно одно авторизованное ADB-устройство. Используются лишь `adb devices`, точечные `getprop`, запросы `cmd package resolve-activity/query-activities` для HOME, `pm list packages` и варианты `-d/-e`.

В JSON:
- `matches-baseline` — исходный HOME и пакеты совпадают по доступным полям;
- `review-required` — найдены различия в `home.differs`, `packages.changed_state`, `absent_from_device`, `new_since_baseline`;
- `P-04B comparison STOPPED` — не удалось доверенно проверить данные или состояние системы.

Во всех сценариях `home_switch_blocked=true`. **Никаких действий по восстановлению не выполняется.** Вывод может содержать имена отличающихся приложений; проверяй его перед отправкой.

## Почему это ещё не полноценный откат

1. Наличие заводского Google TV Launcher в перечне кандидатов не гарантирует возможность безопасно вернуть его активным HOME на Android 9.
2. Нельзя автоматически удалять появившиеся после снимка приложения или бездумно включать весь список пакетов.
3. Требуется проверенный резервный доступ к управлению при отказе ADB, пульта и HOME.
4. Snapshot не содержит прошивку Android, калибровки, Bluetooth pairing, настройки изображения или пользовательские данные.

Отдельная реализация реального восстановления возможна только после офлайн-тестов, проверки аварийного управления и явного разрешения владельца. Пока `ModeJob.PROJECTOR_HOME_SWITCH_AUDITED=false`.
